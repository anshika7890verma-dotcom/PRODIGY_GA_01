# PRODIGY_GA_01 – Markov Chain Text Generation

## 📌 Project Overview
This project implements a Markov Chain Text Generation model using Python. It learns word-to-word transition patterns from a custom text dataset and generates new text based on a user-provided starting word.

## 🎯 Objective
To understand how Markov Chains use probability and existing text patterns to generate new sequences of words.

## 🛠️ Technologies Used
- Python
- Google Colab
- Random
- Regular Expressions (re)
- Collections (defaultdict and Counter)

## ⚙️ Methodology
1. Created a custom text dataset.
2. Converted the text into lowercase and extracted individual words.
3. Built a first-order Markov Chain model by counting consecutive word transitions.
4. Generated text using weighted random selection.
5. Tested the model using different starting words.

## ▶️ How to Run
1. Open the `.ipynb` notebook in Google Colab.
2. Run the cells in sequence.
3. Enter a starting word when prompted.
4. Enter the desired number of words.
5. View the generated text.

## 📊 Results
The model successfully generated text using different starting words, including artificial, machine, python, technology and generative.

## 📚 Learning Outcomes
- Understanding Markov Chains.
- Learning probability-based text generation.
- Working with Python dictionaries and counters.
- Understanding basic Natural Language Processing concepts.
